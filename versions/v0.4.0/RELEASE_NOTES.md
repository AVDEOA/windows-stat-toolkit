# Release Notes v0.4.0

## Added
- First compiled desktop exe concept for network diagnostics.
- Host add/edit/delete flow for SSH-managed Windows PCs.
- AI bundle generation with a hard 30 MB cap.
- PC summary and per-block report buttons.
- Telegram-backed concept monitoring.

## Changed
- The product is now centered on a .NET 8 WPF desktop app rather than script-only or script-wrapped UX.
- Build and release wrappers now publish a self-contained `win-x64` single-file exe.

## Fixed
- Corrected the product path to match the clarified goal: a full desktop program instead of a script-first toolkit.
