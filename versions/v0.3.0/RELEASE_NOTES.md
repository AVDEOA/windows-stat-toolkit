# Release Notes v0.3.0

## Added
- Desktop WPF GUI for local diagnostics, analyzer runs, SSH host management, and bundle browsing.
- Shared GUI application layer that exposes local overview data, recent reports, host inventory, and saved bundle metadata.

## Changed
- The main user-facing workflow is now GUI-first instead of command-first.
- Product docs and state files now describe the desktop app as the default entrypoint.

## Fixed
- Corrected the product direction after clarification that the toolkit should be a desktop program with a convenient interface, not just a script MVP.
