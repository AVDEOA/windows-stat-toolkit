# Известные проблемы

## Текущие
- Критических проблем в структуре набора пока не обнаружено.
- При запуске через оболочку WSL прямой вызов `powershell.exe` потребовал выход за пределы песочницы, поэтому Windows-проверка выполняется с повышенными правами.
- Для русских строк в Windows PowerShell 5.1 потребовалась кодировка `UTF-8 with BOM`; без BOM возможны ошибки разбора скриптов.

## Обнаружено в диагностических отчётах системы
- Найдены предупреждения `Microsoft-Windows-Kernel-PnP` с `Event ID 219`: драйвер `\Driver\vmbusr` не загрузился для `ROOT\VMBus\0000`.
- Найдено критическое событие `Kernel-Power` `Event ID 41`, указывающее на некорректное завершение работы или внезапную перезагрузку.
- Найдено событие `EventLog` `Event ID 6008` о предыдущем неожиданном завершении работы.
- Найдены ошибки `Service Control Manager`, включая проблемы `netprofm`, `HvHost`, `Nested Network Virtualization` и `VMSP`.
- Найдены ошибки `WindowsUpdateClient` при установке нескольких пакетов Microsoft Store / runtime с кодами `0x80240016` и `0x80073D02`.
- По блокам WHEA/PCIe, GPU TDR/DirectX и BugCheck/BSOD явных критических аппаратных ошибок и событий BSOD в отчётах не найдено.

## На контроле
- Некоторые командлеты Windows могут отсутствовать в зависимости от редакции Windows, установленных компонентов и уровня прав.
- Часть журналов событий и источников сведений о надёжности может быть недоступна без административных прав.
- Сведения о драйверах, аппаратном здоровье и диагностике устройств могут отличаться в зависимости от производителя оборудования и версии Windows.
