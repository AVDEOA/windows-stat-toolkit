# Контекст задачи

## Цель
Создать структурированный набор PowerShell-скриптов для диагностики Windows в режиме только чтения в текущей папке проекта.

## Ожидаемый результат
- Отдельные PowerShell-скрипты для независимого запуска диагностических блоков
- Один мастер-скрипт для запуска всех блоков за один проход
- Человеко-читаемый и удобный для ChatGPT текстовый вывод
- Отчёты с временной меткой, сохраняемые в `C:\Stat`
- Постоянные файлы памяти задачи, чтобы не терять прогресс, найденные проблемы и уже выполненные исправления

## Ограничения безопасности
- Только диагностика
- Без изменений реестра
- Без изменения служб, драйверов и системной конфигурации
- Без установки программ
- Без команд перезагрузки и выключения
- Единственные допустимые изменения в системе: создание `C:\Stat` и запись туда файлов отчётов
