Windows Stat Toolkit

Назначение
- Набор PowerShell-скриптов для безопасного чтения диагностических данных Windows.
- Инструмент помогает собрать факты о системе и подготовить структурированные отчеты для ручного или AI-анализа.

Основные сценарии
- `Run-All-Stat-Collection.ps1`: запускает все диагностические блоки и сохраняет отчеты.
- `AnalizeV9.ps1`: анализирует найденные сигналы за выбранный период.
- `Validate-Toolkit.ps1`: проверяет синтаксис и ищет запрещенные изменяющие команды.

Главные файлы
- `StatToolkit.Common.ps1`: общие функции и форматирование отчетов.
- `Block1` ... `Block7`: тематические блоки диагностики.
- `Analize.ps1` ... `AnalizeV9.ps1`: поколения анализатора.

Как использовать
1. Откройте Windows PowerShell.
2. Перейдите в папку со скриптами.
3. Для проверки набора выполните `.\Validate-Toolkit.ps1`.
4. Для полного сбора выполните `.\Run-All-Stat-Collection.ps1`.
5. Для анализа выполните `.\AnalizeV9.ps1` и выберите период.

Замечания
- Скрипты предназначены для Windows.
- Полный сбор отчетов пишет текстовые файлы в `C:\Stat`.
- Базовый режим работы задуман как только чтение, без изменений системы.
